# 第3段階の請求管理・按分

第3段階では、請求項目を設定表で管理し、対象期間の在宅時間比率で請求総額を2人へ按分します。

## シート

- `請求項目`: 請求項目ID、請求元、表示名、有効/無効、表示順
- `請求履歴`: 請求額と対象期間、入力者、計算状態
- `按分結果`: 計算ごとの在宅時間、比率、丸め前金額、確定金額

`請求項目`には電気、ガス、水道の初期行を作成します。請求元や表示名は実際の契約先に合わせて編集できます。

## 請求を計算する

1. `請求履歴`の末尾へ次を入力する。
   - `bill_id`: 重複しない8文字以上のID
   - `billing_item_id`: `請求項目`にある有効なID
   - `period_start`: 対象開始日時
   - `period_end`: 対象終了日時（この日時は集計に含めない）
   - `amount_yen`: 0以上の整数
   - `entered_by`: 入力者
   - `entered_at`: 入力日時
   - `calculation_status`: `PENDING`
2. Apps Scriptで`processPendingBills`を実行する。
3. `請求履歴`の計算状態と`按分結果`を確認する。

## 計算ルール

- 負担割合は`個人の有効在宅時間 / 2人の有効在宅時間合計`。
- 片方の在宅時間が0で、もう片方が正の場合は`0% / 100%`。
- 2人とも0の場合は`NEEDS_DECISION`とし、均等割りや手動金額を自動確定しない。
- 判定不能時間がある場合は、暫定額を計算して`NEEDS_REVIEW`とする。
- 1人目を四捨五入し、2人目を`請求総額 - 1人目`として円単位の合計を必ず一致させる。
- 再計算時は新しい`calculation_id`で`按分結果`へ追記し、過去の結果を残す。
